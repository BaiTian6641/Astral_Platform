# S10 · 安全子系统

> | 属性 | 值 |
> |---|---|
> | 仓库 | ethereal-runtime / ethereal-fabric / ethereal-spec |
> | 许可证 | MIT / CERN-OHL-S-2.0 |
> | 重要度 | ★★★☆☆（v1 防事故；v3+ 防攻击，商业版分水岭） |
> | 关联 | ADR-009；任务 E2-SEC1、E3-SEC2；上游多租户 FPGA 安全综述（ACM TRETS 2025） |

## 1. 是什么 / 做什么 / 重要度

平台安全的分层体系：**L0 结构安全**（fabric/代理 IO 的物理隔离）、**L1 装载安全**（验签/能力清单）、**L2 运行安全**（region 锁/看门狗/异常监控）、**L3 内容安全**（虚拟配置静态检查——overlay 特有的"比特流杀毒"）、**L4 多租户**（侧信道/故障注入防御，商业版）。

**为什么重要**：坦率的分层让项目在安全叙事上诚实且专业：v1 面向单业主可信环境（防事故），但每一层都在架构上预留接口，多租户故事（防攻击）作为商业级特性逐步解锁。overlay 路线还有一个独特红利：**配置数据是我们自定义格式，静态扫描恶意结构（环振、短路）比分析厂商比特流容易得多**。

## 2. 大体规划

| 层 | 机制 | 阶段 |
|---|---|---|
| L0 | region 虚拟路由边界；IO 不直达引脚（S06）；配置口 region 锁矩阵（S02） | P1-P2 |
| L1 | Ed25519 强制验签（S09）；capabilities.yaml 与 IO 分配校验（S06） | P2（E2-SEC1） |
| L2 | 看门狗/restartPolicy（S07）；region 功耗/温度异常监控→自动隔离 | P2-P3 |
| L3 | **虚拟配置静态检查器**：扫描帧数据中的环振（组合环）、非法多驱、耗尽型布线模式；可插拔钩子（S09 M-S09-3） | P3（E3-SEC2） |
| L4 | 侧信道缓解指南（floorplan 隔离带）、故障注入检测（电压/时钟毛刺传感器评估）、TEE/远程证明 | P5（商业版） |

## 3. 详细规划与阶段检查点

### Phase 1（L0 基础）
| # | 步骤 | 检查点 |
|---|---|---|
| 1 | region 锁矩阵（随 S02 E0-FAB5/E1 联合） | 越权 region 写被拒且事件上报 |
| 2 | IO 结构隔离（随 S06） | 容器逻辑无直达引脚路径（网表检查脚本） |

### Phase 2（L1+L2，E2-SEC1）
| # | 步骤 | 检查点 |
|---|---|---|
| 1 | 强制验签开关默认开启 | 未签名/坏签名镜像拒绝 |
| 2 | 能力清单校验（capabilities vs 分配的 IO/服务） | 越权 IO 请求拒绝；测试矩阵全过 |
| 3 | 异常监控 v1（重构次数突增/看门狗频发→标记） | 注入异常模式被标记并限流 |

### Phase 3（L3，E3-SEC2）
| # | 步骤 | 检查点 |
|---|---|---|
| 1 | 环振/组合环检测（对配置帧做网表重建+环检测） | 构造的恶意样本 100% 检出；误报率报告 |
| 2 | 功耗/时序异常监控（经 S07 遥测） | 环振样本运行时电流异常被检测并隔离 |
| 3 | 检查器可插拔接口 + 安全公告流程（SECURITY.md） | 第三方检查器 demo |

### Phase 5（L4，商业版）
- 多租户威胁模型白皮书；floorplan 隔离带规则；远程证明评估；侧信道测试报告。

## 4. 验证与里程碑验收

**方法**：攻击用例集（恶意镜像样本库：环振/短路/资源耗尽/越权访问）→ 检出率/误报率统计 → 红蓝演练（自己构造攻击自己防）→ 外部评审（Phase 3 后邀请社区安全研究者）。

| 里程碑 | 验收标准 |
|---|---|
| M-S10-1（P2） | L1 强制化上线；能力校验矩阵全过 |
| M-S10-2（P3） | L3 检查器检出率/误报率报告发布 |
| M-S10-3（P5） | 多租户威胁模型白皮书 |

## 5. 可能的问题与快速查找关键词

| 问题 | 症状 | 搜索关键词 |
|---|---|---|
| 环振检测误报（合法异步逻辑） | 误杀正常镜像 | `ring oscillator detection netlist`、`FPGA bitstream antivirus false positive` |
| 时序型环振绕过静态检测 | 漏检 | `FPGA malware timing based oscillator`；配合 L2 电流监控兜底 |
| 能力清单粒度设计 | 过粗/过细 | `capability based security embedded`；参考 AkiraOS capability guard |
| 侧信道无法彻底防 | 叙事风险 | `multi-tenant FPGA side channel survey`；文档诚实声明威胁模型边界 |
| 密钥管理流程缺失 | 生态信任危机 | `sigstore cosign keyless signing`（Phase 4 评估借鉴） |
