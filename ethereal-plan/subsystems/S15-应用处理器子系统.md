## 1. 是什么 / 做什么 / 重要度

应用处理器子系统是平台的**用户侧通用处理器**——类比 Zynq 的 ARM PS。它给最终用户提供
**可 boot Linux、全系统可达、可运行自定义固件**的计算能力，与 fabric（虚拟逻辑容器）、
BMC（管理面）并列为一等公民。

三要素：
1. **可配置 RISC-V 核心集群**（目标 RV64 / RVA23 方向，≤4 核；用户可配 RV32/RV64、单/多核），
   挂在**标准 AXI4 插座**后可插拔（用户可换任意满足插座的核心）；
2. **可配置 DMA 子系统**：一个**多通道 DMA**（通用数据搬运）+ 一个 **2D 图形 DMA**（含像素处理）；
3. **封装式 DRAM 组件**：标准 AXI4 内存从机接口，按目标封装（Zynq-PS / GW5-hard-DDR3 / 未来自研
   DDR 控制器，tapeout 目标）。

**为什么重要**：没有它，平台只有"管理面（BMC）+ 可配置逻辑（fabric）"，用户无法跑真正的
软件栈。有了它，Ethereal 成为完整的"FPGA 容器主机 + 通用处理器"平台——这是从"FPGA 虚拟化"
走向"FPGA 操作系统"的关键一跃。

## 2. 核心集群（可配置 + 可插拔）

### 2.1 标准 AXI4 集群插座（冻结接口，核心可换）

插座是唯一契约（ADR-016 `bmc_core` 模式在应用域的推广）：

| 接口 | 规格 | 用途 |
|---|---|---|
| Master port(s) | AXI4 (+ATOP 原子，SMP 必需) → 系统 `axi_xbar` | 访存/访外设 |
| Interrupts | PLIC + CLINT 作为 AXI MMIO 从机 | Linux 标准中断 |
| Debug | JTAG/cJTAG DTM 引脚（可换） | GDB |
| Config 描述 | `core.yaml`（XLEN/核数/MMU/H/V/缓存/总线宽） | 驱动生成 wrapper + device tree |

**核心可换是结构性的**：SoC 胶合只依赖插座，不依赖具体核心。用户可插 CVA6 /
VexRiscv-SMP / Rocket / 未来的 RVA23 核心。

### 2.2 可配置核心生成器（`app_cluster.sv`，同 fabric_gen 约定）

| 参数 | 取值 | 说明 |
|---|---|---|
| `CORE` | `cva6_cv64a6` / `vexriscv_smp` / `external` | 核心选择 |
| `XLEN` | `32` / `64` | RV32（VexRiscv）/ RV64（CVA6） |
| `CORE_COUNT` | `1` / `2` / `4` | 单/双/四核 |
| `H_EXT` | `0` / `1` | Hypervisor（CVA6 v5.1.0+） |
| `MMU` | `sv32` / `sv39` | 按核心 |
| `ICACHE/DCACHE` | 大小 | 按核心 |

### 2.3 核心选项（研究依据 §rva23-cluster-dma-research.md）

| 核心 | ISA/MMU | SMP | 许可 | ~LUT | 生成器 | 角色 |
|---|---|---|---|---|---|---|
| **CVA6 cv64a6** | RV64GC+H, Sv39 | 主线无（多核=研究级 Culsans） | SHL-0.51 | 47-70K/核 | 纯 SV（参数化） | **RV64 / RVA23 方向默认** |
| **VexRiscv-SMP** | RV32IMAC, Sv32 | 2-8 核相干（drop-in） | MIT | 13-20K/四核 | 预生成 Verilog | **RV32 SMP / 立刻可 boot Linux** |
| XiangShan（未来） | RV64+RVA23 完整 | 是 | MulanPSL | ≫1M（server 级） | Chisel | **真 RVA23 → tapeout/大 FPGA** |

⚠️ **诚实约束（§3.1 of ADR-018）：** 现无**许可宽松的开源全 RVA23 RV64 核**（唯一
XiangShan 太大、Chisel、MulanPSL）。"RVA23 + ≤4 核 + 装得下 GW5AST-138(138K)"
**今日互斥**。故：**138K 上 = 单核 CVA6 或 四核 VexRiscv-SMP**；**4 核 RV64 =
Zynq US+ / tapeout 目标**。插座不变，未来真 RVA23 核直接插入。

### 2.4 GW5AST-138 可行性（诚实）
- 1× CVA6（~47-70K）或 4× VexRiscv-SMP（~13-20K）均装得下（须给 overlay 留预算）；
- 4 核 CVA6 装不下；真 RVA23 核不存在。**138K 应用集群 = 单 CVA6 或 四 VexRiscv-SMP**。

## 3. DMA 子系统（处理器子系统内，可配置）

| 引擎 | 基座 | 可配置项 | 用途 |
|---|---|---|---|
| **多通道 DMA** | **PULP `iDMA`**（SHL，AXI4+ATOP，ND-strided，多通道，硅验证） | 通道数/总线宽/缓冲深度 | 通用数据搬运：app-cluster(Linux dmaengine)、BMC(<10ms 热替换帧 DMA)、region 数据 |
| **2D 图形 DMA** | **iDMA `tensor_ND` + 自研 SV blit/fill/ROP 级** | HSIZE/VSIZE/STRIDE（VDMA 兼容）；ROP/blend/rotation 构建开关 | 2D 块/跨行/tile 搬运 + blit/fill/ROP/alpha-blend/色彩转换/旋转；**Service-Tile 级加速器（S11）** |

- **多通道 DMA → PULP `iDMA`**：唯一许可宽松、纯 SV、AXI 原生、ND-strided、多通道、
  Verilator 友好的开源 DMA。
- **2D 图形 DMA**：iDMA 给 2D/ND strided **搬运**，无像素操作（无 ROP/blend）——加一小段
  **自研 SV blit/fill/ROP 流水线**到其 stream 后端（无许可宽松的开源 BitBLT 可用；DB9100 专有）。

## 4. 封装式 DRAM 组件

SoC 只经标准 **`eth_dram_ctrl` AXI4 内存从机接口**访 DRAM；实现按目标：

| 目标 | 实现 | 状态 |
|---|---|---|
| Zynq US+ | Zynq PS DDR（AXI HP 口） | 封装于 `hal/zynq/glue/` |
| Gowin GW5 | GW5 hard-DDR3 PHY+控制器 IP | 封装于 `hal/gowin/glue/`（ADR-017：非可推断块，附 **Verilator stub**） |
| Tapeout（未来） | **自研开源 DDR 控制器** | **预留插座**（AXI4 从机接口即契约） |

- 解耦"用哪个 DDR"问题：应用集群永远看到同一 AXI4 内存从机；目标 HAL 提供它。
- GW5 hard-DDR3 封装是**硬件 bring-up 任务**（维护者）；在此之前 GW5 应用集群跑
  **无 DDR 配置**（BootROM + 片上 SRAM + 可选外部 SPI-flash/PSRAM rootfs）。
- **Verilator 可验证性保留**：每个 DRAM 实现附行为级 AXI4 内存 stub（ADR-017）。

## 5. Boot 与软件栈

```
BootROM(BSRAM) → OpenSBI(M-mode) → U-Boot(S-mode) → Linux kernel(S-mode)
```
- hartid + DTB 指针经 `a0`/`a1`（标准 RISC-V boot ABI）；`core.yaml` 生成 device tree。
- PLIC + CLINT 作为 AXI MMIO 从机（Linux 标准驱动）。
- VexRiscv-SMP：`linux-on-litex-vexriscv`（OpenSBI + Buildroot，全脚本化）；
  CVA6：`cva6-sdk`（ZSBL→OpenSBI→U-Boot→Linux）。

## 6. 分阶段（工作量估）

| 阶段 | 范围 | 工作量 |
|---|---|---|
| **P-A0** | 1 核（默认 CVA6 cv64a6 或 VexRiscv-SMP）经插座接 AXI；Verilator/iverilog sim；OpenSBI+Linux sim boot | ~1-2 周 |
| **P-A1** | 集群接 AXI/NoC + EMRI 可见管理；fabric/region 访问 | ~1-2 周 |
| **P-A2** | 核心数 1→2→4（配置旋钮），共享 L2，相干 DMA（VexRiscv-SMP 路线） | ~1 周 |
| **P-A3** ⚠️ | **DRAM 路径**（GW5 hard-DDR3 封装 / Zynq-PS DDR / 无 DDR 配置） | 高风险 / 硬件 |
| **P-A4** | 多通道 iDMA + 2D 图形 DMA 集成；Linux dmaengine + 驱动 | ~2 周 |
| **P-A5** | Linux 发行版（Buildroot）、用户固件流、ethctl 集成 | 持续 |
